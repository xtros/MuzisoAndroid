Muziso Android Engine Features

Core native Android innovations engineered for high-resolution bitstreams and battery efficiency.

Foreground MediaSession

Integrates directly with Android OS MediaSessionCompat, providing lockscreen controls, notification shade actions, and WearOS / Android Auto compatibility.

Noisy Audio & Bluetooth

Listens for ACTION_AUDIO_BECOMING_NOISY: instantly pauses when wired headphones are disconnected or incoming calls ring, and resumes on Bluetooth reconnect.

Low-Power Kotlin Engine

Built with Kotlin Coroutines, StateFlow, and ExoPlayer hardware audio offloading to deliver all-day playback with minimal battery drain.

Direct OkHttp CDN Stream

Sub-30ms audio resolution directly from high-speed CDN bitstreams. No server proxies or intermediary transcoding delay.

Smart Deduplication

Deterministic shuffle history preservation and automatic collapse of duplicate soundtrack albums while retaining distinct studio language dubs.

Encrypted Room SQLite DB

Zero cloud tracking. User playlists, liked songs, history, and offline file registry remain exclusively on-device in typed Room DAOs.

📱 Step-by-Step Android Sideloading Instructions:

  1. Tap the Download ARM64 APK (or your device architecture) button above on your Android phone or tablet.
  2. Once downloaded, tap the .apk notification in your Android shade or open it from your Downloads folder.
  3. If prompted "For your security, your phone is not allowed to install unknown apps", tap Settings → toggle on "Allow from this source".
  4. Tap Install. Open Muziso and enjoy high-fidelity 320 kbps streaming!

Core Android Architecture Components

Component Layer Description
MuzisoAudioService Foreground Service Manages Jetpack Media3 ExoPlayer lifecycle, notification bar controls, and lockscreen media session.
JioSaavnResolver Repository / Network Direct 320 kbps sub-30ms audio URL resolution using OkHttp client.
MuzisoRoomDatabase Persistence (Room) Local Android SQLite database storing offline audio files, history, and playlists.
HeadsetReceiver BroadcastReceiver Handles noisy audio intent (auto-pause on headphone disconnect / resume on Bluetooth).

Developer Build Instructions (Android Gradle)

Prerequisites: JDK 17+ and Android SDK Platform 34 (Android 14/15).

Terminal (Clone & Build APK) 
# 1. Clone repository
git clone https://github.com/xtros/MuzisoAndroid.git
cd MuzisoAndroid

# 2. Build Debug APK
./gradlew assembleDebug

# 3. Build Production Signed Release APK
./gradlew assembleRelease

Muziso Android Privacy Policy

Effective Date: February 19, 2026 • 100% Offline-First Architecture

🛡️ Privacy Commitment

Muziso Android is an open-source application created by Webs By JTS. We respect your privacy and operate under a 100% local, offline-first privacy architecture. Muziso does not collect, track, store, or transmit your personal data, audio files, search queries, or listening habits.

📊 Android Permissions & Data Handling

1. Local Storage Only

All playlist entries, liked tracks, offline download indexation, and settings are saved strictly on your local Android device via Room SQLite. None of this data is uploaded to cloud servers.

2. Anonymous Streaming Requests

When streaming online tracks, Muziso queries official CDN endpoints (JioSaavn / Spotify Web API). Requests contain strictly anonymous song/artist IDs with zero user identifying cookies or tracking tokens.
