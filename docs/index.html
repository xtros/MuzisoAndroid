📱 Step-by-Step Android Sideloading Instructions:

  1. Tap the Download ARM64 APK (or your device architecture) button above on your Android phone or tablet.
  2. Once downloaded, tap the .apk notification in your Android shade or open it from your Downloads folder.
  3. If prompted "For your security, your phone is not allowed to install unknown apps", tap Settings → toggle on "Allow from this source".
  4. Tap Install. Open Muziso and enjoy high-fidelity 320 kbps streaming!

Developer Build Instructions (Android Gradle)

Prerequisites: JDK 21 (Eclipse Temurin recommended) and Android Studio Ladybug / Meerkat or newer.

Terminal (Clone & Build Variants) 
# 1. Clone repository
git clone https://github.com/xtros/Muziso-Android.git
cd Muziso-Android

# 2. Build FOSS Universal Release APK
./gradlew assembleFossMobileUniversalRelease

# 3. Build GMS Release APK (with Google Cast)
./gradlew assembleGmsMobileUniversalRelease

# 4. Build Architecture-Specific Release APKs
./gradlew :app:assembleStandaloneMobileArm64Release
./gradlew :app:assembleStandaloneMobileArmeabiRelease
./gradlew :app:assembleStandaloneMobileX86_64Release
./gradlew :app:assembleStandaloneMobileX86Release

Muziso Android Privacy Policy

Effective Date: February 19, 2026 • 100% Offline-First Architecture

🛡️ Privacy Commitment

Muziso Android is an open-source application developed by Webs by JTS for Muziso under a 100% local, offline-first privacy architecture. Muziso does not collect, track, store, or transmit your personal data, search queries, or listening habits.

📊 Android Permissions & Data Handling

1. Local Storage Only

All playlist entries, liked tracks, offline download indexation, and settings are saved strictly on your local Android device via Room SQLite. None of this data is uploaded to cloud servers.

2. Anonymous Streaming Requests

When streaming online tracks, Muziso queries official CDN endpoints (YouTube Music / JioSaavn). Requests contain strictly anonymous stream tokens with zero user tracking cookies.
