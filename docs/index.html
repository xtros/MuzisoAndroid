Complete Native App Feature Matrix

Detailed breakdown of all features, services, and native Android capabilities in Muziso.

Dual-Source Streaming & Sync

YouTube Music Innertube integration with PO token fallback profiles + JioSaavn sub-30ms 320 kbps direct bitstreams. Log in with YouTube Music to sync library, liked songs, and custom playlists.

Word-by-Word Synced Lyrics

Real-time syllable and word-accurate karaoke highlighting aggregated across 6 providers: BetterLyrics, Musixmatch, LRCLib, KuGou, RushLyrics, and SimpMusic, with Romanization and live translation.

Spotify 640x640 Artwork Engine

Automatic high-resolution album cover resolver fetching official Spotify 640x640 artwork across search results, discographies, and local music files with version-preserving smart deduplication.

10-Band Graphic EQ & DSP

Full 10-band hardware graphic equalizer with acoustic presets, bass boost, ReplayGain/LUFS volume normalization, silence skipping, and real-time tempo/pitch shifting.

Listen Together & Discord RPC

Real-time group listening rooms over WebSocket via MuzisoServer. Broadcast your current song and album art to Discord Rich Presence, and scrobble directly to Last.fm.

SponsorBlock & ShazamKit

Crowdsourced SponsorBlock automatically skips sponsored segments and non-music intros. Integrated ShazamKit / ACRCloud identifies songs playing nearby with a single tap.

Google Cast & Android Auto

Stream directly to Google Chromecast, Nest Audio, and smart speakers. Fully compatible with Android Auto dashboard controls, WearOS smartwatches, and home widgets.

Material You & AMOLED Dark

Dynamic wallpaper-based color adaptation, Pure Black AMOLED power-saving mode, custom player canvas styles, and interactive Muziso Wrapped listening recaps.

100% Local Encrypted Room DB

Sandboxed offline song cache, custom playlists, and listening history stored exclusively on-device in typed Room SQLite DAOs with zero analytics or telemetry.

Developer Build Instructions (Android Gradle)

Prerequisites: JDK 21 (Eclipse Temurin recommended) and Android Studio Ladybug / Meerkat or newer.

Terminal (Clone & Build Variants) 
# 1. Clone repository
git clone https://github.com/xtros/Muziso-Android.git
cd Muziso-Android

# 2. Build FOSS Universal Release APK
./gradlew assembleFossMobileUniversalRelease

# 3. Build GMS Release APK (with Google Cast)
./gradlew assembleGmsMobileUniversalRelease

# 4. Build Architecture-Specific Release APKs
./gradlew :app:assembleStandaloneMobileArm64Release
./gradlew :app:assembleStandaloneMobileArmeabiRelease
./gradlew :app:assembleStandaloneMobileX86_64Release
./gradlew :app:assembleStandaloneMobileX86Release

Muziso Android Privacy Policy

Effective Date: February 19, 2026 • 100% Offline-First Architecture

Privacy Commitment

Muziso Android is an open-source application developed by Webs by JTS for Muziso under a 100% local, offline-first privacy architecture. Muziso does not collect, track, store, or transmit your personal data, search queries, or listening habits.

Android Permissions & Data Handling

1. Local Storage Only

All playlist entries, liked tracks, offline download indexation, and settings are saved strictly on your local Android device via Room SQLite. None of this data is uploaded to cloud servers.

2. Anonymous Streaming Requests

When streaming online tracks, Muziso queries official CDN endpoints (YouTube Music / JioSaavn). Requests contain strictly anonymous stream tokens with zero user tracking cookies.
